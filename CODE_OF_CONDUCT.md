# Code of conduct

This project follows the spirit of the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), version 2.1.

In short:

- Be kind and patient. Assume good intent, and remember that many people here write in a second language.
- Criticise code and claims, not people. Disagreement backed by a measurement is always welcome.
- No harassment, insults, sexual language or personal attacks, in public or in private.
- Do not publish other people's private information.
- Do not use this project's spaces to advertise. Mentioning your own tool where it helps is fine, with a
  short note that you made it.

## Reporting

If someone breaks these rules, report it privately through
[GitHub's private reporting](https://github.com/salahmakboul/call4agents/security/advisories/new)
(write "conduct" in the title), or use GitHub's "Report content" on the comment. The maintainers will read
every report, keep it confidential, and may edit or remove comments, or block someone from the project.
