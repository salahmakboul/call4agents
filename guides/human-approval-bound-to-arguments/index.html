Human approval that binds to the exact arguments

A "yes" to pay(10, alice) must not run pay(9999, mallory), and one "yes" should cover one action. How to bind an approval to what was shown.

The gap

Human-in-the-loop flows usually work like this: the agent proposes a call, the run pauses, a person approves, and the run continues from saved state. Two things can go wrong:

  • The arguments change after the "yes". The saved state can be edited (by a bug, a migration, or anyone with write access), or the model can be asked again after a restart and propose different arguments.
  • One "yes" runs twice. A double click, two workers picking up the same task, or a resume after a crash can run the approved action again.

Bind the "yes" to the call, and spend it once

import call4agents as c4a
c4a.init()                     # the approval secret lives in .c4a/secret

@c4a.effect(approval=True)
def pay(amount: int, to: str) -> str:
    return payments.charge(amount=amount, to=to)

with c4a.run("order-42"):
    c4a.approve(pay, amount=10, to="alice")   # what the person SAW
    pay(amount=10, to="alice")                # runs once
    pay(amount=9999, to="mallory")            # ApprovalRequired: not what was approved
    c4a.deny(pay, amount=10, to="alice")      # a later "no" is enforced

The approval is an HMAC over the tool name and the exact arguments, scoped to the run, made with a local secret. Each approval can be spent by one action. Many callers racing on one "yes": exactly one runs.

What it does not protect against: someone who can read the secret file, and a person approving the wrong thing.
